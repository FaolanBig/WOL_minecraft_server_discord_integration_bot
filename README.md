# WOL_minecraft_server_discord_integration_bot

A self-hosted Discord bot for waking a Minecraft Java server over Wake-on-LAN,
reporting its status, stopping Minecraft after 15 minutes with no players, then
powering off its Linux host after another 15 minutes without a new start request.

See [doc/SETUP.md](doc/SETUP.md) for Discord, Minecraft, and Docker setup instructions.
