Power up.
Power down.

A small, self-hosted relay keeps the whole lifecycle in sync.

01
DISCORD/start

Send the signal

An authorized member runs /start. Already online? The bot lets you know.

02
WOL

Bring the host online

If needed, Wake-on-LAN powers up the host; restricted SSH starts Minecraft.

03
◔

Wind down gracefully

After 15 empty minutes, Minecraft stops. If it stays stopped another 15, the host can power off.

↳ The bot runs on a separate, always-on Linux machine on the same LAN as your Minecraft host.

Get the bot running with Docker Compose. First, follow the full guide to configure the Minecraft host, RCON, Wake-on-LAN, and restricted SSH.

Read the complete setup guide
YOU’LL NEED
01 Discord application
02 Always-on Linux host
03 Minecraft host on your LAN
QUICK START / TERMINAL LOCAL

# Clone the project

$ git clone https://github.com/FaolanBig/WOL_minecraft_server_discord_integration_bot.git
$ cd WOL_minecraft_server_discord_integration_bot

# Configure your environment and secrets

$ cp .env.example .env && chmod 0600 .env
$ mkdir -p secrets

Edit .env and add your SSH key + known_hosts to secrets/

# Build, start, and follow the logs

$ docker compose up --build -d
$ docker compose logs -f minecraft-discord-bot
FOLLOW THE SETUP GUIDE BEFORE DEPLOYINGDOCKER COMPOSE
!

Built for your LAN, not the public internet. Keep RCON private, protect your Discord token and SSH key, and verify host keys. Host power-off is an explicit, host-specific setup step.
